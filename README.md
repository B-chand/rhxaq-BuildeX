# Task Manager

A simple **Task Manager web application** built with **Node.js, Express, and MS SQL Server**.  
This project allows users to **add, update, delete, and manage tasks** with a clean UI built using **Bootstrap 5**.

---

## Features

- Add new tasks with title and description  
- Update task status via backend (MS SQL stored procedure)  
- Delete individual tasks  
- Clear all tasks  
- Fully connected **frontend (`index.html`) to backend (`server.js`)**  

---

## Tech Stack

- **Frontend:** HTML, Bootstrap 5, JavaScript  
- **Backend:** Node.js, Express  
- **Database:** MS SQL Server (`TaskManagerDB`)  
- **DB Connection:** `tedious` package for Node.js
